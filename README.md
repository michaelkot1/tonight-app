# Tonight

Social what-to-watch app — Expo (SDK 57) + Expo Router + Supabase.

## Get started

```bash
npm install
npx expo start
```

Open in Expo Go, iOS simulator, or Android emulator.

## Env

Copy `.env.example` → `.env` and fill `EXPO_PUBLIC_SUPABASE_*`. Never commit `.env`.
TMDB / OMDb keys stay server-side (see `.env.example`).
